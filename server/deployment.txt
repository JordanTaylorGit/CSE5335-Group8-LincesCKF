### 3. How to Deploy to AWS EC2
Here is a high-level guide to getting your Node/React app running on an EC2 instance:

1. **Launch an EC2 Instance:** Go to the AWS Console, launch an Ubuntu instance (t2.micro is fine for starters), and ensure you open **Port 80 (HTTP)**, **Port 443 (HTTPS)**, and **Port 22 (SSH)** in the Security Group.
2. **SSH into the Server:** Connect to your instance via terminal: `ssh -i your-key.pem ubuntu@your-ec2-ip`
3. **Install Dependencies:** Run the following commands to install Node.js, Nginx, and MySQL on the server:
   ```bash
   sudo apt update && sudo apt upgrade -y
   sudo apt install nodejs npm nginx mysql-server -y
   ```
4. **Set Up MySQL:** Log into MySQL (`sudo mysql`), create your database, run the initialization script above, and create a user with a secure password.
5. **Clone Your Repository:** Pull down your code onto the server (`git clone https://...`).
6. **Build the Frontend:** 
   - Navigate to the `client` folder.
   - Run `npm install` and then `npm run build`.
   - Your compiled frontend files will be in the `dist` or `build` folder.
7. **Start the Backend Server with PM2:**
   - Install PM2 globally: `sudo npm install -g pm2`
   - Navigate to your `server` folder, run `npm install`.
   - Create a `.env` file with your `JWT_SECRET` and MySQL credentials (`DB_USER`, `DB_PASSWORD`, `DB_NAME`, etc.).
   - Start the server: `pm2 start server.js --name "linces-backend"`
   - Save the PM2 process to run on startup: `pm2 startup` and `pm2 save`.
8. **Configure Nginx (Reverse Proxy):**
   - Edit the Nginx config (`sudo nano /etc/nginx/sites-available/default`).
   - Configure it to serve your React static files from the `client/dist` directory on `/` and proxy `/api` requests to `localhost:5001`.
   ```nginx
   server {
       listen 80;
       server_name yourdomain.com;

       # Serve React App
       location / {
           root /path/to/your/client/dist;
           try_files $uri /index.html;
       }

       # Reverse Proxy for Node Backend
       location /api/ {
           proxy_pass http://localhost:5001;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
           proxy_cache_bypass $http_upgrade;
       }
   }
   ```
9. **Restart Nginx:** `sudo systemctl restart nginx`
10. **(Optional but Recommended) Setup SSL:** Use Let's Encrypt / Certbot to secure your server: `sudo apt install certbot python3-certbot-nginx` and run `sudo certbot --nginx`.

This setup will successfully serve your React frontend and proxy all data requests natively to your newly migrated MySQL backend!
